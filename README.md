# Pixel Clash Vereinszentrale – Weboberfläche

[Zur Vereinszentrale](https://grofolki.github.io/pixel-clash-vereinszentrale-web/)

Dieses Repository enthält ausschliesslich die fertige Browseroberfläche und öffentliche Recherche. Die Anmeldung verwendet die bestehenden Pixel-Clash-Konten. Vereinsdaten, Dokumententwürfe und Nachweise werden über Supabase durch Anmeldung und Rollenprüfung geschützt.

Das private Quellprojekt und die Datenbankmigrationen werden hier nicht veröffentlicht. Keine neue Vereinsmitgliedschaft durch Turnierteilnahme. CHF 30 pro Zweierteam.

Eine Person mit Super-Adminrechten kann vorhandenen Websitekonten eine Vereinsrolle zuweisen. TWINT-Produktivzahlungen, automatische Bankabrufe und E-Mail-Versand sind noch nicht verbunden.
